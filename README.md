# 🧠 Problem Solving

A major focus of this repository is learning **how to think about programming problems**.

The general approach followed is:

```text
Understand the Problem
        ↓
Identify Inputs and Outputs
        ↓
Study Constraints
        ↓
Think of a Brute Force Solution
        ↓
Analyze Time Complexity
        ↓
Find the Bottleneck
        ↓
Look for a Better Approach
        ↓
Choose the Right Data Structure
        ↓
Implement
        ↓
Test Edge Cases
        ↓
Optimize
```

The objective is to understand the reasoning behind a solution instead of simply memorizing code.
